# Glossary

| Term | Meaning |
| --- | --- |
| SuiteScript 2.x / 2.1 | NetSuite's JavaScript API for customization (`N/*` modules) |
| SuiteScript 1.0 | The legacy API (`nlapi*`), still found in many accounts |
| SuiteQL | SQL-like (Oracle-flavored) query language for NetSuite data, via `N/query` or REST |
| Saved Search | UI-based query; used in dashboards, workflows, scripts and emails |
| User Event (UE) | Server script that runs when a record loads, before submit or after submit |
| Client Script (CS) | Script that runs in the browser on a record form |
| Workflow (SuiteFlow) | Point-and-click, state-based automation |
| Workflow Action Script | Script invoked from a workflow |
| Script Deployment | Record that activates a script for a record type or context |
| RESTlet | Custom REST endpoint written in SuiteScript |
| Suitelet | Custom page or endpoint written in SuiteScript |
| Map/Reduce, Scheduled | Server-side batch scripts |
| Governance / usage units | Per-script execution quota; when exhausted, the script is stopped |
| SDF | SuiteCloud Development Framework; deploys customizations as XML plus files |
| ACP | Account Customization Project (an SDF project for a single account) |
| SuiteApp | Packaged application for many accounts |
| Sandbox | Copy of a production account used for testing |
| Release Preview | Preview account for the next NetSuite release (twice a year) |
| AI Connector Service | Oracle's official MCP server for NetSuite (OAuth 2.0) |
| MCP | Model Context Protocol, an open standard for connecting AI to tools and data |
| BYOK | Bring Your Own Key — the user supplies their own AI API key |
| MV3 | Chrome Manifest V3 |
| MAIN / ISOLATED world | The page's JavaScript context vs the extension's content-script context |
| Native Messaging | Chrome mechanism for talking to a local application |
| Merchant of record | Payment provider that sells on your behalf and handles global sales tax/VAT |
