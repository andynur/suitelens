# Support development

Contributions, reproducible redacted bug reports, documentation improvements and fixture-based tests
help keep SuiteLens for NetSuite free. See the repository contribution guide for setup and conventions.

Financial sponsorship is optional and never affects feature availability or safety checks.
GitHub Sponsors and Ko-fi / Buy Me a Coffee links will appear here only after the maintainer supplies
verified active URLs. No payment destination is inferred from a username, and no payment widget or
tracking script is embedded.
