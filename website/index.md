# See the NetSuite context in front of you

SuiteLens for NetSuite is a free, open-source side panel for developers, admins and consultants.
Explore record fields, scripts, workflows, SuiteQL and possible change-impact references using
your own session and role.

> Public release is pending Web Store approval, docs hosting and npm publication. Install from
> source today; do not treat fixture validation as live account proof.

[Install from source](install.html) · [Explore features](features.html) · [Set up local MCP](mcp.html)

## Start with the record

Field IDs and metadata, automation context, read-only queries and saved-payload inspection share
one workbench. Account/environment indicators help you see where you are working. Feature toggles
and Safe mode keep the workbench under your control.

## Decide what leaves your browser

Core data and caches stay local. Optional AI uses your key and asks for a preview. Optional local
MCP requires session/account approval and can expose results to your coding agent and its provider.
Local feature counters are off by default and have no automatic upload.
